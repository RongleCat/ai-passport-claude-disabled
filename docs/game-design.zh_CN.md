# 达里奥封号检测仪

## 1. 项目定位

**达里奥封号检测仪**是一款运行在 AI Passport 设备上的像素风讽刺小游戏。

主题围绕：

> 对 Anthropic 账号风控、地区限制、误封、申诉等现象进行荒诞化、游戏化表达。

游戏通过极简的随机事件，让玩家不断积累“封号风险”，最终进入封号和申诉流程。

整体体验强调：

- 一眼看懂
- 三键即可操作
- 单局时间短
- 适合线下设备循环体验
- 强调荒诞感与传播性
- 不采集真实隐私数据
- 不进行真实身份、IP、地区识别

---

# 2. 硬件适配原则

目标设备：

**AI Passport**

主要约束：

- 屏幕尺寸：240 × 320
- ESP32-C3
- 8MB Flash
- 无 PSRAM
- 上 / 下 / 确认三个实体按键

因此整个游戏采用：

- 单屏单任务
- 极少文字
- 小尺寸像素素材
- LVGL 原生控件为主
- 不使用视频
- 不使用整屏高分辨率图片
- 不使用复杂透明动画
- 页面切换后销毁上一页资源

# 5. 达里奥角色设计

达里奥使用原创 Q 版像素形象。

基础特征：

- 卷发
- 深色眼镜
- 深蓝色西装
- 一本正经的表情
- 企业安全审查员气质

准备 4 个基础状态：

### 正常

🙂

用于：

- 首页
- 普通检测

### 怀疑

🤨

用于：

- 中风险事件
- 可疑行为检测

### 高风险

😠

用于：

- 风险超过 70%

### 封号

😈

用于：

- 最终 BAN 页面
- 申诉失败页面

推荐尺寸：

**64×64 或 80×80 px**

角色动画只使用轻量效果：

- 眨眼
- 上下移动 1～2 像素
- 左右摇晃
- 短暂震动

不做复杂逐帧动画。

# 6. 核心玩法

每局从事件池中随机抽取：

**3 个事件**

完整流程：

```text
首页
 ↓
开始检测
 ↓
扫描动画
 ↓
随机事件 1
 ↓
随机事件 2
 ↓
随机事件 3
 ↓
最终封号
 ↓
申诉
 ↓
游戏结束
```

单局目标时长：

**约 30～45 秒**

# 15. 随机事件规则

事件池：

```text
赠送额度
安全验证邮件
中国人检测
VPN 瞬移
什么都不做
```

每局：

```text
随机抽取 3 个
```

同一局：

**不重复事件。**

风险值根据玩家选择和事件结果累计。

无论实际累计风险是多少，完成第三个事件后都会进入最终安全审查。

## 标题

建议：

**不超过 8 个汉字**

## 正文

最多：

**2 行**

## 每行

建议：

**8～10 个汉字以内**

---

```text
检测到异常

```

```text
系统检测您的账户可能存在
```

```text

系统检测到您的设备
可能存在中文使用环境
```

- 不使用大面积 Alpha 图片

- 中文字体只保留项目实际使用的字符
- 音频保持短小
- 所有游戏逻辑离线运行

# 28. 数据结构建议

事件统一为配置形式：

```c
typedef struct {
    int id;
    const char* title;
    int type;
    int risk_a;
    int risk_b;
```

事件池：

```text
EVENT_GIFT
EVENT_EMAIL
EVENT_CHINA_SCAN

```

# 33. 最终目标

这个游戏不依赖复杂剧情和大量文字。

核心体验只需要让用户理解三个东西：

> **做什么都可能增加风险。**

> **系统总能找到一个封号理由。**

> **最后甚至连申诉也像一个随机小游戏。**

最终形成一个：

**30～45 秒即可完整体验、容易理解、容易围观、容易拍摄传播的像素风讽刺小游戏。**
